# wagmi-rainbowkit-integration

## When to use

User wants the frontend to read from or write to a deployed contract. You already know the address (from `read_deployed_address`) and the ABI (from `sync_abi_to_frontend`).

## Stack assumptions

```
wagmi:        ^2.19.x
viem:         2.38.x
@rainbow-me/rainbowkit: ^2.2.x
@tanstack/react-query:  ^5.55.x
next:         16.x  (App Router)
react:        19.x
```

## Provider tree (already in repo, don't break it)

`frontend/app/providers.tsx`:
```tsx
'use client';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { WagmiProvider } from 'wagmi';
import { RainbowKitProvider } from '@rainbow-me/rainbowkit';
import { config } from '../wagmi';

const queryClient = new QueryClient();

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <RainbowKitProvider>{children}</RainbowKitProvider>
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

`frontend/wagmi.ts` ships with sepolia gated by `NEXT_PUBLIC_ENABLE_TESTNETS`. **Do not** remove that flag. The integration agent may add additional chains ONLY when the user explicitly asks; otherwise leave it as-is and rely on Sepolia.

`frontend/app/layout.tsx` already imports `'@rainbow-me/rainbowkit/styles.css'`. Don't duplicate that import.

## Address constants — single source of truth

Always use `frontend/lib/contracts.ts`, generated by `write_contract_address_constants`:

```ts
export const CONTRACT_ADDRESSES = {
  [11155111]: {
    Counter: "0xabc..." as const,
  },
} as const;
export type SupportedChainId = keyof typeof CONTRACT_ADDRESSES;
export type ContractName = keyof typeof CONTRACT_ADDRESSES[SupportedChainId];
```

Never hardcode `0x...` inline in components.

## Reading state — useReadContract

```tsx
'use client';
import { useReadContract } from 'wagmi';
import { counterAbi } from '@/abi/Counter';
import { CONTRACT_ADDRESSES } from '@/lib/contracts';

const SEPOLIA = 11155111 as const;

export function CounterReader() {
  const { data, isLoading, error, refetch } = useReadContract({
    abi: counterAbi,
    address: CONTRACT_ADDRESSES[SEPOLIA].Counter,
    functionName: 'number',
  });

  if (isLoading) return <p>Loading…</p>;
  if (error)     return <p className="text-red-500">{error.message}</p>;
  return <p>Count: {String(data ?? '—')}</p>;
}
```

Notes:
- `data` is fully typed because `counterAbi` is `as const`.
- `useContractRead` (v1) is removed in v2 — use `useReadContract`.
- `refetch()` after a write to update without a page reload.

## Writing state — useWriteContract + receipt

```tsx
'use client';
import { useAccount, useWriteContract, useWaitForTransactionReceipt } from 'wagmi';
import { counterAbi } from '@/abi/Counter';
import { CONTRACT_ADDRESSES } from '@/lib/contracts';

const SEPOLIA = 11155111 as const;

export function IncrementButton() {
  const { isConnected } = useAccount();
  const { writeContract, data: hash, isPending, error } = useWriteContract();
  const { isLoading: isMining, isSuccess } = useWaitForTransactionReceipt({ hash });

  const onClick = () =>
    writeContract({
      abi: counterAbi,
      address: CONTRACT_ADDRESSES[SEPOLIA].Counter,
      functionName: 'increment',
    });

  if (!isConnected) return <p>Connect wallet first.</p>;

  return (
    <div>
      <button disabled={isPending || isMining} onClick={onClick}>
        {isPending ? 'Confirm in wallet…' : isMining ? 'Mining…' : 'Increment'}
      </button>
      {hash && <p>tx: {hash}</p>}
      {isSuccess && <p>Confirmed.</p>}
      {error && <p className="text-red-500">{error.message}</p>}
    </div>
  );
}
```

## Connect button

`frontend/app/page.tsx` already uses RainbowKit's `<ConnectButton />`. Drop it into any layout where the wallet is needed:

```tsx
import { ConnectButton } from '@rainbow-me/rainbowkit';
<ConnectButton />
```

## Patterns to follow

- **Always** mark the file `'use client';` if it imports `wagmi`, `@rainbow-me/rainbowkit`, or `@tanstack/react-query` hooks.
- **Always** guard writes with `useAccount().isConnected`.
- **Always** show pending + mining + error states; users hate silent buttons.
- **Always** import addresses from `@/lib/contracts`, not literals.
- **Always** import ABIs from `@/abi/<Name>`.
- **Default chain** stays Sepolia. To support more chains, add to `wagmi.ts` AND `CONTRACT_ADDRESSES` in lockstep.

## Anti-patterns

- ❌ `useContractRead` / `useContractWrite` (v1, removed)
- ❌ `useNetwork` (v1, removed) — use `useAccount().chainId`
- ❌ `usePrepareContractWrite` (v1) — v2 inlines this into `useWriteContract`
- ❌ Hardcoded addresses in component files
- ❌ Calling write hooks from server components

## Verifying integration

After wiring up:

1. `pnpm_run_build` — must succeed; types must check (this is where missing `as const` shows up).
2. `pnpm_dev_smoke` — server returns 200, body is non-empty.
3. `sandbox_get_preview_url(3000)` — share with the user.
4. Tell the user: "Connect wallet → switch to Sepolia → click [button] → check tx in MetaMask".
